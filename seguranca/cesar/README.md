# Cifra de César

Página interativa que ensina a cifra de César, uma das formas mais antigas de criptografia. Basta abrir o `index.html` no navegador, não precisa de servidor nem internet.

O elemento central é uma roda com dois anéis do alfabeto: o externo fixo, o interno giratório. Arraste a roda com o mouse (ou o dedo) pra deslocar o alfabeto, com encaixe suave em cada uma das 26 posições, ou use as setinhas de +1/-1. No modo "Cifrar", digite uma mensagem e veja o texto cifrado ao vivo. No modo "Decifrar — desafio", cole uma mensagem cifrada e gire a roda manualmente até ela fazer sentido (tem um botão de ajuda que lista as 26 possibilidades, pra quem travar). Acentos e pontuação passam direto, sem cifrar.
