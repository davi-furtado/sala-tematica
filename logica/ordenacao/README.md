# Corrida de Ordenação

Página interativa que compara algoritmos de ordenação lado a lado, no mesmo array embaralhado. Basta abrir o `index.html` no navegador, não precisa de servidor nem internet.

Cada painel tem um seletor de algoritmo (Bubble Sort, Seleção, Inserção ou Quick Sort) com uma frase curta explicando como ele funciona. Ao clicar em "Iniciar corrida", os dois algoritmos rodam ao mesmo tempo, cada um no seu ritmo real — o mais eficiente termina primeiro de verdade, não por truque de animação. Barras vermelhas mostram comparações/trocas em andamento, barras verdes mostram posições já definitivas, e um slider controla a velocidade geral. Quando os dois terminam, o mais rápido ganha um destaque de vencedor.
