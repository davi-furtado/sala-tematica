# Binário na Prática

Página interativa que mostra como o computador representa texto em binário. Basta abrir o `index.html` no navegador, não precisa de servidor nem internet.

Tem 3 abas:

- **Brinque com os bits** — 8 interruptores soltos. Ao clicar, o bit liga/desliga e mostra na hora o valor decimal do byte e, se der, o caractere correspondente.
- **Digite seu nome** — ao digitar, cada caractere acende uma fileira de LEDs com o byte dele em UTF-8, mostrando o valor decimal, o binário e o próprio caractere. Letras com acento usam mais de 1 byte, e isso aparece na tela.
- **Tabela de referência** — lista os caracteres ASCII com seu decimal, binário e LEDs, para consulta.
